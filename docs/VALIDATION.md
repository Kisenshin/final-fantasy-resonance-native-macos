# 验证范围与发布状态

[简体中文](VALIDATION.md) | [English](VALIDATION.en.md)

整理日期：2026-10-25。本项目为实验性源码适配；公开发布不代表已经完成从零构建验证。

## 已完成的轻量检查

- Python 源文件可通过 AST 语法解析。
- 运行时补丁可应用到 `upstream.json` 指定的原始提交；15 个修改／新增文件的结果逐一匹配导出时记录的 SHA-256。
- 由整理后工具源码计算出的 shader chain 为 `e09c9cc1f074`，与运行时头文件及当前本机游戏使用的链版本一致。
- 尚未验证的实时 GPU 采样实验不在发布补丁中。
- FPS 菜单资源编辑函数，在本机已有的两个原始资源上生成与此前运行验证版本相同的 SHA-256；两个 chunk 的 BLAKE3 metadata 哈希也一致。检查时没有复制整个游戏容器，测试输入没有放进仓库。
- 构建入口默认返回计划，未传入 `--build` 时不下载、不解包、不编译、不启动游戏。
- 发布文件清单与文本审计检查：见 `release-files.json`，可运行 `python scripts/audit_release.py` 重查。

## 运行观察与本目录的区别

此前的本机版本已经在 M1 Pro、macOS 26.5.1 上运行，并测试过起始场景、中文、声音、保存／读档以及原游戏 30／60 帧菜单的选择和持久化。键盘映射和虚拟手柄快照也做过检查。它是利用本机工作区逐步构建与更新出来的版本。

**这些观察不是对本目录新构建入口的从零验证。** 这里新整理了准备运行时、构建编排、从用户资源应用 FPS 补丁和应用打包的入口，它们只完成了上述轻量检查。

## 明确未完成

- 全新目录从原始 NSP 和自有密钥到最终 `.app` 的端到端构建。
- 本入口的联网拉取、依赖全新安装、完整编译、完整打包签名及中断恢复验证。
- 独立机器复现、其他 Apple Silicon GPU／系统组合验证。
- 全章节通关、稳定 60 帧保证、所有 DLC 功能及实体手柄组合测试。
- 火焰／透明粒子闪烁的完整修复，以及战斗首次特效卡顿的完整解决。

用户选择暂不进行占用大量空间的完整重建。本轮没有修改现有安装应用、存档或游戏资源，也没有重编译着色器。
