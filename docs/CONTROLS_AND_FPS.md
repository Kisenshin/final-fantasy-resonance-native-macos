# 键盘、手柄与游戏内 30／60 帧设置

[简体中文](CONTROLS_AND_FPS.md) | [English](CONTROLS_AND_FPS.en.md)

以下操作适用于港版 1.0.1 的本机适配应用。新的源码构建入口仍未完成全新环境端到端验证，见 [验证状态](VALIDATION.md)。

## 连接与提示方式

先通过 macOS 将手柄连接好，再切回游戏并按下按键或移动摇杆。适配层使用 Apple GameController 读取手柄；设备需要能被该框架识别，不能据此保证所有第三方兼容手柄都可用。

- 按键盘时，窗口底部提示栏切为键盘映射。
- 操作 Xbox 或 Switch Pro 时，底部提示栏切为相应手柄。
- F1 打开完整对照表，F2 显示／隐藏底部提示栏；也可使用顶部 `Controls` 菜单。MacBook 如将 F1／F2 作为亮度键，需要配合 Fn 使用。
- **自动变化的是适配层的底部提示栏。原游戏内部的 Switch 按键图案仍保留，尚未将每一处图案替换成键盘或 Xbox 图标。** 请按下表转换。

## 按键对照

Xbox 采用按字母映射：**A 确认、B 返回**。Switch Pro 保持自己的原布局。因此两个手柄的确认键物理位置不同，不要只按位置类比。

| 游戏中的 Switch 提示／功能 | 键盘 | Xbox | Switch Pro |
| --- | --- | --- | --- |
| A：确认／对话 | J 或空格 | A（下方） | A（右侧） |
| B：返回 | K、Esc 或 Backspace | B（右侧） | B（下方） |
| X | U | X（左侧） | X（上方） |
| Y | I | Y（上方） | Y（左侧） |
| 左摇杆：移动 | W、A、S、D | 左摇杆 | 左摇杆 |
| 右摇杆 | Option＋方向键，或数字小键盘 4／6／8／2 | 右摇杆 | 右摇杆 |
| 十字键 | 方向键 ↑↓←→ | 十字键 | 十字键 |
| L／R | Q／E | LB／RB | L／R |
| ZL／ZR | Z／C | LT／RT | ZL／ZR |
| 按下左／右摇杆 | F／G | L3／R3 | 按下左／右摇杆 |
| ＋：系统菜单 | Enter | Menu | ＋ |
| − | Tab | View | − |

表中 X／Y、肩键等仅说明与 Switch 按键的对应关系，具体战斗动作以游戏当前提示为准。键盘数字小键盘 4／6 对应右摇杆左／右，8／2 对应上／下；不带 Option 的方向键为十字键。

窗口切到后台会释放输入；摇杆有小幅死区以减少漂移。实体手柄的连接、无线稳定性和兼容型号仍需更多实机验证。现有映射通过 Apple GameController 虚拟快照检查，覆盖面键、双摇杆、按下摇杆、十字键、肩键、扳机与 Menu／View。体感、振动、Home／截图键不在此次适配范围内。

## 在原游戏菜单切换 30／60 帧

入口：**游戏内「系统菜单 → 选项 → 画面设置 → 帧率」**。标题画面的 `Option` 也可进入同一设置。

1. 进入场景后打开系统菜单：键盘 **Enter**，Xbox **Menu**，Switch Pro **＋**。在标题页则直接选择 `Option`。
2. 进入「选项」，切换到「画面设置」。切换标签使用游戏的 L／R：键盘 **Q／E**，Xbox **LB／RB**，Switch Pro **L／R**。
3. 用方向输入选中「帧率」，按确认打开下拉框：键盘 **J／空格**，两类手柄均为 **A**。
4. 在 **30** 和 **60** 中选择，再按确认。此适配只保留这两个选项。
5. 执行游戏的 **Y「套用／应用」**：键盘按 **I**，Xbox 按 **Y（上方）**，Switch Pro 按 **Y（左侧）**。
6. 在确认框选择「是」，再按确认：键盘 **J／空格**，Xbox／Switch Pro **A**。

完成应用后设置即时生效，并由游戏自己的 `OptionSaveData` 保存。本机旧工作区版本已验证保存 30、重启恢复 30，以及保存 60、重启恢复 60。只改变下拉框而没有执行应用，不应视为设置已经保存。

顶部 `Performance` 菜单显示的是当前目标档位，修改入口统一在原游戏选项中。**选择 60 FPS 只是帧率目标，不代表实测每一帧都达到 60。** 战斗特效、首次创建资源或其他开销仍可能造成掉帧；60 帧属于实验功能。

## 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 底部仍显示键盘 | 先确认 macOS 已连接手柄，再实际按键或移动摇杆；提示不会仅因连接了设备就一定切换。 |
| 画面里仍是 Switch 图标 | 这是当前实现范围，查本页对照表或按 F1；底部提示切换不等于所有游戏内图标都已替换。 |
| Xbox 确认／返回位置与 Switch Pro 不同 | 按字母操作：两者均为 A 确认、B 返回；Xbox A 在下方，Switch Pro A 在右侧。 |
| F1／F2 变成亮度等系统操作 | 尝试 Fn＋F1／F2，或使用顶部 Controls 菜单。 |
| 重启后帧率选择没有保存 | 重新选择、执行 Y 套用，并在确认框选择「是」后按 A；键盘对应 I，再 J／空格。 |
| 找不到帧率一行 | 核对是否为支持的港版 1.0.1，以及构建日志中的 FPS 菜单补丁是否成功；不要用其他版本的资源强行覆盖。 |
| 选择 60 后仍偶发掉帧 | 60 是目标值。可先切回 30 对照，报告发生场景及日志；不能据此宣称已稳定 60 或已修好全部特效。 |

## 全屏、退出与存档

- 全屏：**Control＋Command＋F**，或窗口绿色全屏按钮；也可使用顶部 `Window → Enter Full Screen`。
- 退出：**Command＋Q**。
- 正式应用存档目录：`~/Library/Application Support/FFRNative/0100B8A026F14000/save`。

本项目不提供存档；构建脚本不会打包已有存档。当前粒子显示问题和偶发卡顿见 README 的已知限制。
